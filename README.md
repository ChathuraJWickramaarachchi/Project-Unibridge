# UniBridge – Internship & Permanent Job Platform 💼

UniBridge is a full-stack MERN-based Internship and Permanent Job Platform designed to bridge the gap between students, graduates, and employers. The platform enables companies to publish job opportunities while allowing users to search, apply, and track internship and permanent job applications through a modern and user-friendly interface.

---

## 🚀 Features

- Student & employer registration and authentication
- Internship and permanent job listings
- Advanced job search and filtering
- Online job application system
- Resume/CV upload and management
- Employer dashboard for job posting management
- Applicant tracking and status updates
- User profile management
- Secure authentication with email verification
- Responsive design for desktop and mobile devices

## 🎯 User Roles

### 👨‍🎓 Student
- Register/Login
- Build profile
- Upload Resume/CV
- Search internship & job opportunities
- Apply for jobs
- Track application status

### 🏢 Employer
- Register/Login
- Create company profile
- Post internship & job vacancies
- View applicants
- Manage applications
- Update application status

### 👨‍💼 Admin
- Manage users
- Approve or remove companies
- Monitor job postings
- Manage reports and platform activities
